IKON V3 Android Launcher starter

This is a native Android Java starter project. It:
- lists launcher-visible installed apps
- filters them with search
- launches an app when tapped
- declares itself as a possible HOME launcher

Build:
1. Upload this project folder to a GitHub repository.
2. Commit the files to the main branch.
3. Open the repository's Actions tab.
4. Run "Build IKON APK" (or let the push trigger it).
5. Open the completed workflow run and download the "IKON-V3-debug" artifact.
6. Extract the artifact to get app-debug.apk.

Important:
- The APK is a debug prototype, not a Play Store release.
- You need an Android device to install/test it and choose IKON as the Home app.
- This project is built in GitHub's cloud runner, not on the Windows 7 laptop.
- Do not install the APK on an unknown device; only test on a device you are allowed to use.
